# 用户指南

## 快速开始

1. 打开应用（Web 浏览器或 Android APK）
2. 首次使用：点击"注册"，填写用户名和密码
3. 登录后进入课程表主页
4. 点击右下角 **「导入课表」** 按钮
5. 选择导入方式：URL 导入、JSON/ICS 文件导入、或教务系统直连
6. 导入后即可查看周视图或日视图

---

## 登录与注册

### 注册

在登录页点击"注册"，填写：

- **用户名**：3-50 个字符，不可与已有用户重复
- **密码**：至少 6 个字符
- **昵称**（可选）：最长 100 个字符

注册成功后自动登录并跳转到课程表主页。

### 登录

输入用户名和密码，点击登录。登录状态通过 JWT Token 保持，关闭应用后重新打开无需重新登录。

### 登出

点击顶部导航栏右侧的 **退出图标**，确认后清除本地 Token 和离线缓存。

## 课程表主页

路由：`/`

### 视图切换

顶部 **「周视图」/「日视图」** 分段按钮控制显示模式：

- **周视图**：横向显示周一至周日，纵向 12 节课（默认 1-12 节）。每节课卡片显示课程名和教室。
- **日视图**：仅显示今天（当前星期几）的课程，卡片更大，信息更清晰。

### 课程卡片

点击任意课程卡片，弹出详情对话框显示课程名和上课地点。

### 课表切换

顶部日历图标下拉菜单可切换多个课表（如果有多个导入记录），按导入时间倒序排列，当前选中项以勾选图标标记。

### 切换日期（日视图）

在日视图下，顶部日期行可左右滑动或点击不同星期切换日期。

### 宽屏侧栏

在宽度 > 850px 的屏幕上（如 Web 浏览器），右侧显示：

- **天气卡片**：随机展示一条趣味天气和上课提醒
- **未排课课程**：有课程名但没有具体节次的课程列表

### 小恐龙游戏

在课表空白区域（右侧留白），点击即可玩内置的 Chrome Dino 小游戏。

## 导入课表

路由：`/import`

三种导入方式：

### 1. URL 导入

输入一个指向 `.ics`（iCalendar）或 `.json` 文件的 URL，点击「导入」。系统自动检测格式并解析。

支持的文件格式：
- **ICS**：iCalendar 日历格式，常见于教务系统导出、Google Calendar、Apple Calendar
- **JSON**：自定义 JSON 格式

### 2. 文件导入

直接上传本地的 `.ics` 或 `.json` 文件（功能开发中，当前通过 URL 导入为主）。

### 3. 教务系统直连

选择学校（目前仅支持「福州大学至诚学院」），输入教务系统账号、密码、学年和学期：

1. 如果启用验证码：系统先获取验证码图片 → 用户手动输入 → 登录 → 自动抓取课程表
2. 如果未启用验证码：系统自动识别（需配置字模表）→ 登录 → 抓取

导入成功后自动跳转回课程表主页。

## 数据来源管理

路由：`/sources`

查看所有课表的导入来源，包括：

- 原始 URL
- 来源类型（ICS / JSON / HTML）
- 同步状态（idle / syncing / success / failed）
- 最后同步时间

点击来源进入详情页（`/sources/:id`），可查看同步历史记录。

### 增量同步

在来源详情页点击「同步」按钮，系统重新拉取原始 URL 内容。当前版本同步仅更新来源元数据（ETag、状态），不更新课表内容。

---

## 管理员面板

路由：`/admin`

仅 `admin` 角色用户可见。

### 用户管理（`/admin/users`）

- **用户列表**：分页展示所有用户（用户名、昵称、角色、创建时间）
- **搜索**：按用户名模糊搜索
- **创建用户**：手动添加用户（指定用户名、密码、昵称、角色）
- **编辑用户**：修改昵称、角色或重置密码
- **删除用户**：级联删除用户的所有数据（课表、课程、课次、地点、来源、同步记录）。**至少保留一个管理员**。

### 统计概览

显示总用户数、管理员数、总课程表数。

---

## 离线缓存

课表数据自动缓存到本地存储：

- **课表列表**：登录后自动缓存，下次打开无需等待网络
- **课表详情**：查看某个课表后缓存，离线也可查看
- **缓存清理**：登出时自动清除该用户的缓存

缓存的课表不含完整课程数据（仅摘要），详情需进入具体课表后缓存。

## 常见问题

| 问题 | 解决 |
|------|------|
| 主页显示"暂无课表" | 点击右下角「导入课表」按钮导入 |
| 教务系统导入提示"验证码错误" | 刷新验证码后重新输入；如果持续失败，检查账号密码 |
| 教务系统导入提示"暂无课程记录" | 确认学年和上下学期选择正确 |
| URL 导入失败 | 确认 URL 可直接访问（非内网地址）；文件格式为 ICS 或 JSON |
| 日视图没有课 | 检查当天是周几；如果当天确实没课则显示空 |
| 课表卡片重叠 | 同一时间段有多节课时可能重叠，属于正常显示 |
| 页面空白或加载失败 | 刷新页面；检查后端 API 是否正常运行 |
| Web 端连不上 API | 检查 `API_URL` 配置；本地开发时默认连接 `http://localhost:3001` |
| Android 端连不上 API | 模拟器默认连接 `10.0.2.2:3001`；真机需通过 `--dart-define=API_URL=` 指定 |
| 忘记密码 | 联系管理员在后台重置密码 |
| 登录状态丢失 | 可能是 Token 过期或被服务端清理，重新登录即可 |
